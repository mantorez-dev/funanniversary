## 🚀 How to Open on Her Phone

### Option A: Free Private Web Link (Recommended)
1. Go to [Vercel](https://vercel.com) or [Netlify Drop](https://app.netlify.com/drop).
2. Drag and drop your `D:\Gift` folder.
3. In 30 seconds you'll get a private link (e.g., `https://our-love-anniversary.vercel.app`) you can send directly to her phone!

### Option B: Local Wi-Fi (Same Home Wi-Fi)
1. In PowerShell inside `D:\Gift`:
   ```powershell
   python -m http.server 8000
   ```
2. On her phone browser, open `http://<your-pc-ip>:8000`.
